# Mobile First

## 390px

- ใช้ one column
- Primary action ต้องเห็นได้ใกล้ page title
- Cards เรียงซ้อนแนวตั้ง
- Forms แบ่งเป็น decision cards ขนาดเล็ก

## 768px

- Fields สั้น ๆ สามารถเป็น two-column grids ได้
- คง primary workflow ให้เป็นเส้นตรง

## 1024px

- เพิ่ม supporting side panels เช่น timeline หรือ summary ได้
- ห้ามเพิ่ม configuration เพียงเพราะมีพื้นที่มากขึ้น

## 1440px

- เพิ่ม scan efficiency ด้วย grids ที่กว้างขึ้น
- คุม content width ให้อ่านสบาย
- Desktop ช่วยเพิ่ม productivity แต่ mobile ยังเป็นแหล่ง truth ของประสบการณ์หลัก
