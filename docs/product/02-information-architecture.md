# Information Architecture

## Primary Navigation

Navigation สำหรับ Production ที่แนะนำ:

1. Dashboard
2. Order Checking
3. Tracking
4. Payments
5. Reports
6. Settings

## Recommendation

แนะนำให้นำ Shipments และ History ออกจาก primary navigation ในช่วงนี้ ลูกค้ามักคิดในมุมการติดตาม Shipment มากกว่าการจัดการ shipment table ส่วน Shipment history สามารถอยู่ใน Tracking และ Reports ได้จนกว่าการใช้งานจริงจะพิสูจน์ว่าควรมีเมนูแยก
