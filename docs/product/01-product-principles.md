# Product Principles

Sisahygo Connect ควรรู้สึกเรียบง่าย รวดเร็ว ทันสมัย เป็นมิตร มืออาชีพ และเบาในการใช้งาน

## Principles

- Mobile first: ออกแบบสำหรับ 390px ก่อน desktop
- Business first: ใช้ภาษางานโลจิสติกส์ ไม่ใช้ภาษาฐานข้อมูลหรือ API เป็นหลัก
- Three interactions: งานหลักควรเข้าถึงได้ภายในสาม interaction
- Card first: ใช้ cards สำหรับการตัดสินใจและ summary ใช้ tables เฉพาะเมื่อจำเป็นต้อง scan ข้อมูลจำนวนมาก
- Progressive disclosure: แสดงเฉพาะสิ่งที่ผู้ใช้ต้องใช้ ณ ตอนนั้น
- Production ready: ทุก component ต้องพร้อมใช้ต่อใน Sprint 2
- Keep it small: หน้าจอน้อยลง settings น้อยลง และ choices น้อยลง

## Product Goals

- ลดเวลารอของลูกค้า
- ลดความผิดพลาดในการส่งรายการ
- เพิ่มการมองเห็นสถานะ Shipment
- เพิ่มความมั่นใจของลูกค้า
- เพิ่มการใช้งาน API
