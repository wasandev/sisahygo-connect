# Design Tokens

## Color

- Primary: Connect Blue
- Secondary: Slate
- Success: Green
- Warning: Orange
- Danger: Red

## Typography

- ใช้ sans-serif UI font
- Page title: 24-30px
- Card title: 16px
- Body text: 14-16px
- ห้ามใช้ negative letter spacing

## Spacing

- Mobile page padding: 16-20px
- Card padding: 20-24px
- Section gap: 24px
- Control gap: 8-16px

## Radius

- Cards และ controls: 8px
- Pills และ badges สามารถ fully rounded ได้

## Shadow

ใช้ subtle shadows เฉพาะ cards, modals และ floating feedback

## Animation

ใช้ transitions เล็กน้อยสำหรับ hover/focus หลีกเลี่ยง decorative motion

## Dark Mode

ยังไม่จำเป็นตอนนี้ แต่ token names ควรเป็น semantic พอให้รองรับได้ในอนาคต
