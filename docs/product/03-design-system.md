# Design System

## Components

Production components อยู่ใต้ `resources/views/components/connect/`

Components ที่สร้างหรือปรับปรุงแล้ว:

- Button
- Input
- Select
- Textarea
- Card
- Stat Card
- Badge
- Search Box
- Timeline
- Page Header
- Empty State
- Loading
- Toast
- Modal
- Pagination

## Interaction Pattern

- Primary action ปรากฏครั้งเดียวต่อ section
- Secondary actions ต้องดูสงบและไม่แย่งความสนใจ
- Cards ใช้จัดกลุ่มหนึ่งการตัดสินใจหรือหนึ่ง summary
- Timeline เป็น visualization หลักของ Tracking
- Empty states ควรแนะนำ next useful action
